# Parivahan-website-revamp

A full-stack repository for the Parivahan Website Revamp project, organized for pair development (Frontend + Backend).

## 📁 Repository Structure
```text
parivahaan-website-revamp/
├── Frontend/               # Client-side web application
│   ├── src/styles/         # Global SCSS Design System (_variables.scss, _mixins.scss, global.scss)
│   └── README.md
├── Backend/                # Server-side APIs and database services
│   └── README.md
├── .gitignore              # Pre-configured Git ignore rules
├── .gitattributes          # Cross-platform line ending rules
└── README.md
```

## 🎨 Global SCSS Architecture
- `Frontend/src/styles/_variables.scss`: Shared color palette, font sizes, spacing.
- `Frontend/src/styles/_mixins.scss`: Reusable layouts, mixins, responsive breakpoints.
- `Frontend/src/styles/global.scss`: Main stylesheet imported across components.

## 🤝 Team Roles & Collaboration
- **Frontend Lead**: Develops client UI and components inside `Frontend/`.
- **Backend Lead**: Develops APIs and server logic inside `Backend/`.
